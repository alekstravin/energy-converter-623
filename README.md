# Энергетический конвертер

Сайт: https://alekstravin.github.io/energy-converter-623/

Конвертация энергетических единиц и пересчёт цены на другую единицу измерения.
Работает в обычном браузере и как Telegram Mini App. Все расчёты выполняются
в браузере; сервер приложения и локальный туннель не нужны.

Коэффициент эффективности газовой генерации в текущей методике — 55%.

## Публикация

GitHub Pages публикует корень ветки `main`. В сайт входят `index.html`,
`fx_latest.json` и `.nojekyll`. Изменения в ветке запускают новую публикацию.

`fx_latest.json` — снимок официальных курсов ЦБ РФ с указанной датой.
Обновление курсов не автоматическое; замените файл новым снимком или введите
курс вручную в приложении. Источник: https://www.cbr.ru/scripts/XML_daily.asp

Недоступность Telegram SDK, файла курсов или browser storage не останавливает
конвертер. После загрузки страницы расчёты также работают без подключения.

Для локального просмотра: `python3 -m http.server 8080`.
